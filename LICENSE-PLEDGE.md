# Tracelane Apache 2.0 License Pledge

**We, the maintainers of Tracelane, publicly commit that:**

1. Tracelane will remain Apache 2.0 licensed for the life of the project.
2. We will never relicense to Commons Clause, Business Source License (BSL),
   Server-Side Public License (SSPL), Elastic License v2 (ELv2), or any other
   license that restricts use as a hosted or managed service.
3. We will never add commercial use restrictions, seat restrictions, or
   deployment restrictions to the Apache 2.0 core.
4. If ownership of the project ever changes hands, the new owner is bound by
   this public pledge for all code committed under Apache 2.0. New code under
   new ownership may carry a different license, but existing Apache 2.0 code
   cannot be relicensed.

**The one exception:** If a hyperscaler captures more than 5% of Tracelane's
revenue by hosting Tracelane as a competing managed service without contributing
back, we reserve the right to add a BSL relicensing clause for *new* releases.
All prior releases remain Apache 2.0 permanently.

This pledge is inspired by the HashiCorp and Elastic cautionary tales, and by
the playbook that made MLflow, Langfuse, and OpenLLMetry successful.
