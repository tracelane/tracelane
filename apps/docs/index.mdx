Tracelane is a Rust gateway and ClickHouse-backed observability tier that
captures every LLM and tool call at full fidelity, with a tamper-evident audit
ledger that makes each run provable. Its sharpest edge is **MCP and agent-tool
safety**: it surfaces tool-definition-drift, rug-pull substitution, and
hallucinated tool-call arguments as first-class signals (drift and rug-pull compare
against a definition you approved in one click from the tools Tracelane has
observed on your own traffic) and records each with a
tamper-evident signature. Heuristic checks for the lethal trifecta and prompt
injection observe alongside, on every request and on every tier. A2A/A2UI drift,
browser stuck-loops and argument drift are **roadmap**: those detectors gate on
payload fields a `/v1/chat/completions` request does not carry, so they do not
fire on LLM traffic today. Gateway-level enforcement is opt-in (observe-first by
default), and an ML ensemble is on the roadmap.

You point traffic at us, get low-overhead gateway routing, full-fidelity
trace capture, tamper-evident audit logs, and merge-gate evals. Premium
positioning, Apache 2.0, no SaaS-blocked license games.

## Why Tracelane

<CardGroup cols={2}>
  <Card title="Apache 2.0, full stop" icon="scale-balanced">
    Not GPL-3.0 viral. Not ELv2 SaaS-blocked. Run it however you want.
  </Card>
  <Card title="Caught at the gateway, not after" icon="bolt">
    Tool-definition-drift is flagged or halted inline at the gateway, not
    reconstructed from an incident write-up.
  </Card>
  <Card title="Every claim carries an eval" icon="circle-check">
    20 conformance evals — 10 fault-tolerance chaos scenarios, 7 gateway-correctness,
    and one each for ingest-schema, PII-redaction and prompt-injection. They run in
    the canonical repository's CI; in this public mirror they ship as readable
    reference, because six of them assert against fixtures the mirror deliberately
    withholds. Structural assertions run green; behavioral ones report as
    **skipped** without a live gateway rather than as a pass.
  </Card>
  <Card title="Tamper-evident ledger" icon="lock">
    SHA-256 hash chain and Ed25519 per-tenant signing, with byte-identical
    verifiers in Rust + Python + TypeScript. Anchored batches carry a resolved
    Sigstore Rekor v2 inclusion proof (best-effort, opt-in); universal per-run
    anchoring is on the roadmap.
  </Card>
</CardGroup>
