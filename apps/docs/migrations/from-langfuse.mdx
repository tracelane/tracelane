Langfuse exposes traces over its own SDK + an OTLP endpoint. Tracelane is
OTel-native, so the pivot is:

1. Keep your Langfuse SDK if you want, but repoint its OTLP exporter.
2. Or swap to `@tracelanedev/sdk` / `tracelane` (Python) and
   delete the Langfuse SDK.

<Note>
  Both paths work on **Tracelane Cloud** and on self-host. On Cloud the OTLP
  endpoint is the gateway, `https://gateway.tracelane.dev`, authenticated with a
  `tlane_…` key carrying the **`ingest`** scope. Self-hosting, it is the ingest
  receiver you run. If you only want the model call captured and not the agent's
  structure, you need no exporter at all — point any OpenAI-compatible client at
  `https://gateway.tracelane.dev/v1` (see the [quickstart](/quickstart)).
</Note>

## Path A — keep the Langfuse SDK

Repoint Langfuse's OTLP exporter. Tracelane accepts **both** OTLP/HTTP wire
formats — protobuf and JSON, selected by `Content-Type` — and
the exporter appends `/v1/traces` to whatever base you give it:

```bash
# Tracelane Cloud
export OTEL_EXPORTER_OTLP_ENDPOINT=https://gateway.tracelane.dev
export OTEL_EXPORTER_OTLP_HEADERS=authorization=Bearer\ tlane_<your_key>

# or a self-hosted ingest receiver you run
# export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4318
```

Langfuse-emitted spans land in your ClickHouse hot tier and the dashboard
renders them. Predictive guardrails won't fire (they need the gateway's
chat path), but observability + audit work.

<Warning>
  **Spans sent this way are stored and queryable, but not hash-chained.** Only
  calls proxied through the gateway's chat path enter the tamper-evident ledger —
  see [the audit ledger](/audit-ledger). This is a property of the SDK path on
  Cloud and self-host alike, not a Cloud limitation.
</Warning>

**On a self-hosted, multi-tenant ingest, `Authorization` is not read at all** —
that deployment enforces SPIFFE mTLS and authenticates the client certificate,
not a bearer token (see [SPIFFE ingest](/security/spiffe-ingest)). The bearer
above is for the Cloud gateway, and for single-tenant self-host it is ignored
because there is exactly one tenant to attribute to.

## Path B — full swap

```bash
npm uninstall langfuse
npm install @tracelanedev/sdk
```

```typescript
import { init, instrumentOpenAI } from "@tracelanedev/sdk";
import OpenAI from "openai";

init({
  endpoint: "https://gateway.tracelane.dev", // or your own receiver
  apiKey: process.env.TRACELANE_API_KEY!,    // needs the `ingest` scope
});

const client = new OpenAI();
instrumentOpenAI(client); // wrap each client you want traced
```

Instrumentation is explicit — after `init()`, wrap each client with its
`instrument*` function (`instrumentOpenAI`, `instrumentAnthropic`,
`instrumentLangGraph`, …). Custom Langfuse `observe(...)` decorators become
standard OpenTelemetry spans via `@opentelemetry/api`
(`trace.getTracer(...).startActiveSpan(...)`).

## Why move

| | Langfuse | Tracelane |
|---|---|---|
| License | MIT (per Langfuse's public licensing) | Apache 2.0 across the board |
| Predictive guardrails | None inline | Eight, on the hot path |
| Tamper-evident audit | None | Hash chain + Ed25519 per-tenant signing (live) + byte-identical 3-language verifier; resolved Sigstore Rekor v2 inclusion proof on anchored batches (best-effort); universal per-run anchoring on the roadmap |
| Routing across providers | Via the SDK | Via the gateway — no SDK swap, single API key |
| Dashboard trace viewer | Standard | In-house transcript-spine viewer (SVG/DOM) |
