Customers who want a neutral, framework-agnostic AI gateway under a permissive Apache 2.0 licence have a clear reason to evaluate an independent alternative.

## How we compare

| Claim | Tracelane | Portkey |
|---|---|---|
| License | Apache 2.0 (full stack, including predictive layer) | Portkey OSS + paid hybrid |
| Self-host | Apache 2.0 full stack; single-node Docker Compose | OSS gateway; paid hosted observability |
| Wire format | OTel GenAI semconv (canonical) | Portkey's own schema; OpenTelemetry support documented as partial |
| Predictive guardrails | Inline heuristic guardrails (multi-model ML ensemble on the roadmap) | Guardrails library (Portkey markets realtime guardrails; verify fit for your policy) |
| Tamper-evident audit ledger | $999 add-on SKU (tamper-evident hash chain + Ed25519 per-tenant signing live; resolved Sigstore Rekor v2 inclusion proof on anchored batches, best-effort; universal per-run anchoring on the roadmap) | — |
| BYOK key custody | Envelope encryption, AAD bound to (tenant_id, provider_id) | BYOK supported |
| Auto-rollback on objective metrics | EWMA drift on metrics you post; not autonomous | Manual prompt promotion |

## FAQ

<AccordionGroup>

<Accordion title="Does Tracelane have feature parity with Portkey?">
On the gateway feature set (150+ providers, failover, retry, BYOK, usage/token tracking) yes. Tracelane adds inline heuristic predictive guardrails (a multi-model ML ensemble is on the roadmap), tamper-evident audit ledger for EU AI Act Article 12, and OTel GenAI semconv as the canonical wire format. Portkey ships a guardrails library; Tracelane ships inline heuristic guardrails that run on every request.
</Accordion>

<Accordion title="How long does migration take?">
Tracelane reads OpenAI-, Anthropic-, and Google-shaped requests directly. Most Portkey configs map 1:1 — provider list, fallback chain, BYOK keys. Cutover is typically an afternoon.
</Accordion>

</AccordionGroup>
